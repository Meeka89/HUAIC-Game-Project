# Assets, permissions, and credits

Track each asset before adding or distributing it: art, music, sound, fonts, writing, and other reused material. Include AI-generated assets. An asset found online is not automatically free to use.

For each asset or clearly identified group, add an entry using these fields:

```text
Asset name and repository path:
Creator and source URL (or original contributor):
Usage permission or license, with evidence/link:
Modifications made:
Required attribution and where it will appear:
AI use, if applicable: tool/model, generation date, and relevant usage terms/source
Permission questions still open:
```

No assets have been added during the initial setup. Record only information that is known; unresolved permission needs review before use or distribution. Do not include private account details or private prompts in credit records.
